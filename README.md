# Monster Brawler

A solo-developed Unreal Engine 5 gameplay prototype showcasing modular combat systems built in C++ and Blueprint.

## Features

- Modular combat component
- Grabbing and throwing system
- Enemy AI
- Health and damage system
- Animation-driven combat
- Gameplay state management

## Technologies

- Unreal Engine 5
- C++
- Blueprints
- Enhanced Input

## About

This repository focuses on gameplay architecture and original systems.
Third-party Marketplace/Fab assets have been excluded from the repository.
